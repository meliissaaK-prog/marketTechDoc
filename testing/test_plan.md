# План тестирования React Marketplace

## Объем тестирования
### Включено в тестирование:
- Главная страница с каталогом товаров
- Страница детальной информации о товаре
- Навигация между страницами
- Адаптивный дизайн

## Подход к тестированию
- **Функциональное тестирование** - проверка работоспособности функций
- **UI тестирование** - проверка интерфейса пользователя
